# คลังผลงาน (Portfolio)

บอทจะส่งรูปในโฟลเดอร์นี้ให้ลูกค้า เมื่อลูกค้าขอดูผลงานตามหมวด

## วิธีเพิ่มรูป
1. วางไฟล์รูปในโฟลเดอร์นี้ เช่น `car-1.jpg`, `accessory-1.jpg`
2. เพิ่มรายการใน `manifest.json` ใต้หมวดที่ต้องการ:

```json
"car": {
  "label": "รถยนต์",
  "items": [
    { "url": "/portfolio/car-1.jpg", "caption": "แคมเปญโชว์รูมรถยนต์ ยอดทักเพิ่ม 3 เท่า" },
    { "url": "/portfolio/car-2.jpg" }
  ]
}
```

- `url` = พาธไฟล์ (ขึ้นต้น `/portfolio/...`) หรือใส่ลิงก์ https เต็มก็ได้
- `caption` = ข้อความใต้รูป (ไม่ใส่ก็ได้)
- หมวดไหน `items` ว่าง = บอทจะไม่รู้จักหมวดนั้น (ปลอดภัย ไม่ส่งรูปพัง)

## หมายเหตุ
- repo นี้เป็น public → รูปในนี้เข้าถึงได้จากลิงก์ตรง เหมาะกับ "แบนเนอร์/ผลงานที่ตั้งใจโชว์ลูกค้า" เท่านั้น อย่าใส่ข้อมูลลับ
- ถ้ารูปเยอะ/ใหญ่มากในอนาคต ค่อยย้ายไป CDN
