# คลังผลงาน (Portfolio)

บอทจะส่งรูปในโฟลเดอร์นี้ให้ลูกค้า เมื่อลูกค้าขอดูผลงานตามหมวด

## วิธีเพิ่มรูป
1. วางไฟล์รูปในโฟลเดอร์นี้ เช่น `car-1.jpg`, `accessory-1.jpg`
2. เพิ่มรายการใน `manifest.json` ใต้หมวดที่ต้องการ:

```json
"car": {
  "label": "รถยนต์",
  "items": [
    { "url": "/portfolio/car-1.jpg", "caption": "แคมเปญโชว์รูมรถยนต์ ยอดทักเพิ่ม 3 เท่า" },
    { "url": "/portfolio/car-2.jpg" }
  ]
}
```

- `url` = พาธไฟล์ (ขึ้นต้น `/portfolio/...`) หรือใส่ลิงก์ https เต็มก็ได้
- `caption` = ข้อความ (ไม่ใส่ก็ได้) — จะขึ้นก่อนรูป/วิดีโอ
- หมวดไหน `items` ว่าง = บอทจะไม่รู้จักหมวดนั้น (ปลอดภัย ไม่ส่งรูปพัง)

## วิดีโอ
อย่าเก็บไฟล์วิดีโอในโฟลเดอร์นี้ (ใหญ่/ช้า) — อัปขึ้น YouTube (unlisted) หรือ Facebook แล้วใส่ลิงก์ในฟิลด์ `video`:

```json
"car": {
  "label": "รถยนต์",
  "items": [
    { "caption": "คลิปตัวอย่างงานถ่ายโชว์รูมค่ะ", "video": "https://youtu.be/xxxx" },
    { "url": "/portfolio/car-1.jpg", "caption": "แคมเปญยอดทักเพิ่ม 3 เท่า" }
  ]
}
```

- 1 item ใส่ได้ทั้ง `caption` + (`url` รูป และ/หรือ `video` ลิงก์)
- Messenger จะขึ้น preview ของลิงก์วิดีโอให้กดเล่นในแชตได้
